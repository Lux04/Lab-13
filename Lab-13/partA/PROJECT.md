# Personal Task Tracker

## Зорилго
Өдөр тутмын task-уудыг удирдах энгийн, хурдан, найдвартай веб аппликаци. AI-assisted workflow ашиглан хөгжүүлэх.

## Scope (5 core features)
1. Task CRUD (Create, Read, Update, Delete)
2. Due Date, Priority (High, Medium, Low), Status (Todo, In Progress, Done)
3. Labels / Tags
4. Search + Filter (by priority, status, due date, keyword)
5. Responsive UI + Dark mode

**Out of scope**: User authentication, multi-user, notifications.

## Техникийн шаардлага
- Backend REST API
- SQLite database
- Clean architecture
