# Stack Comparison

| Stack | Pros | Cons | Сонголт |
|------|------|------|--------|
| Node.js + Express + SQLite | Хурдан development, JS fullstack, lightweight | - | **Сонгосон** |
| Python FastAPI + SQLite | Хурдан API, Pydantic | Frontend-тай холбох илүү ажил | - |
| Next.js Fullstack | SEO, file-based routing | Сургалтын муруй өндөр | - |

**Сонгосон шалтгаан**: Node.js ecosystem, Express simplicity, SQLite zero-config, би Node.js-ийг сайн мэддэг тул AI-тай хамт хурдан хөгжүүлэх боломжтой.
